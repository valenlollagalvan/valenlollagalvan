### 2. SGE - Sistema de Gestión de Expedientes

**Rol:** Software Developer  
**Tipo:** Proyecto académico / portfolio técnico  
**Stack:** C# · .NET · ASP.NET Core Minimal APIs · Blazor WebAssembly · Entity Framework Core · SQLite · JWT · Git

Sistema web para la gestión digital de expedientes administrativos, carátulas, estados y trámites.

El objetivo del proyecto fue construir una solución completa con frontend, backend, autenticación, autorización, persistencia y arquitectura por capas.

**Implementé:**

- WebAPI REST con ASP.NET Core Minimal APIs.
- Frontend administrativo en Blazor WebAssembly.
- Autenticación con JWT.
- Autorización por roles y permisos.
- CRUD de expedientes y trámites.
- Administración de usuarios.
- Manejo global de errores con `ProblemDetails`.
- Persistencia con Entity Framework Core y SQLite.
- Arquitectura separada en Dominio, Aplicación, Infraestructura, WebAPI y Frontend.
- Patrones Repository, Unit of Work e Inyección de Dependencias.
- Health check, rate limiting y configuración por entorno.

**Lo que demuestra este proyecto:**

- Diseño de APIs REST.
- Separación de responsabilidades.
- Modelado de dominio.
- Seguridad básica en aplicaciones web.
- Consumo de API desde frontend.
- Organización de una solución .NET escalable.

🔗 Repositorio: https://github.com/valenlollagalvan/SistemaDeGestionExpedientes
🌐 Demo: https://sistema-de-gestion-expedientes.vercel.app/
